Built for the ten-foot couch

Every interaction is D-pad-native — the accordion category sidebar mirrors the web app's channel list, translated for a remote.

Accordion channel sidebar

12 collapsible categories walked with ↑↓ — the on-air group carries a live marker, and the cursor auto-scrolls to whatever is playing.

Fullscreen zap flow

OK expands the video edge-to-edge; CH+/CH− or ↑↓ flips channels without leaving fullscreen. Any other key drops back to browse with playback intact.

Fail-visible playback

A dead stream shows its reason on screen — never a silent black box. Load any m3u you own from the Settings screen over the IME.

Bring your own playlist

Settings fetches any m3u URL through the bounded host service and adopts it — the starter list is 164 verified-open channels.

Leanback launcher

Installs into the Android TV launcher with the leanback intent — pick it up with the remote like any other TV app.

QuickJS-native

The UI runs as a TenunJS display-list scene on an embedded QuickJS engine — the app logic is TypeScript, the painting is native.

Install

A debug-signed APK — sideload it from a USB stick or the TV's built-in browser.

  1. Download

    Grab NusaTV-AndroidTV-v0.2.0.apk from the releases page — a phone build lives there too.

  2. Allow unknown apps

    Settings → Device Preferences → Security & Restrictions → Unknown sources, enabled for your file manager.

  3. Install & watch

    Open the APK, install, launch NusaTV. First channel plays on OK.
